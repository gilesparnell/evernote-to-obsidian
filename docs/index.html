How it works in one minute

Schema

  • Every note gets type, org, context, people, tags, up written to its YAML frontmatter
  • type drives which MOC the note belongs to via up: wikilink
  • tags include STAR markers, AWS leadership principles, status flags
  • classify_confidence records how certain the classifier was

Pipeline

  • Rules-based scoring runs first (milliseconds, ~66% resolve)
  • Uncertain notes go to Gemma 4 E4B in LM Studio via function calling
  • Notes scoring ≥ 0.80 get frontmatter written automatically
  • Notes < 0.80 land in a review queue for manual classification

MOCs

  • Nick Milo–style Maps of Content with self-maintaining Dataview inbox queries
  • 11 MOCs across two vaults — Meetings, Interview Prep, Leadership, Job Hunt, Patterns…
  • Notes appear automatically the moment up: is written
  • Move into Organised sections as you work through the inbox

End state

  • Zero Evernote/ folders — flat structure in both vaults
  • Work notes live in Business vault, personal notes in Personal vault
  • Every meeting / STAR story / OLR note one Dataview query away
  • Graph view shows clear radial structure centred on MOC hubs
